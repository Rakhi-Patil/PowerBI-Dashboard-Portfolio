# 1. ✈️ Airline Performance Dashboard

## 📌 Overview

The **Airline Performance Dashboard** provides a visual overview of passenger activity and flight status for the year **2022**.

The dashboard allows users to explore passenger trends by day, country, continent, gender, month, and flight status.

### 🎯 Objective

To create an interactive dashboard for understanding:

* Passenger volume
* Flight status distribution
* Passenger activity by continent
* Gender distribution
* Daily passenger trends

### 📊 Key Metrics

| Metric            |               Value |
| ----------------- | ------------------: |
| Total Passengers  |          **98.62K** |
| Cancelled         | **32.94K (33.40%)** |
| Delayed           | **32.83K (33.29%)** |
| On Time           | **32.85K (33.31%)** |
| Male Passengers   |          **49.60K** |
| Female Passengers |          **49.02K** |

### 🔍 Key Insights

* The dashboard represents **98.62K total passengers**.
* Flight status is almost evenly distributed between cancelled, delayed, and on-time passengers.
* **Cancelled flights:** 32.94K (33.40%).
* **Delayed flights:** 32.83K (33.29%).
* **On-time flights:** 32.85K (33.31%).
* **North America** has the highest passenger count at approximately **32K**.
* **Asia** follows with approximately **19K passengers**.
* Oceania, Europe, Africa, and South America have comparatively lower passenger volumes.
* Passenger distribution by gender is almost balanced, with **49.60K male** and **49.02K female** passengers.
* Daily passenger activity fluctuates throughout January, reaching approximately **300 passengers** at its highest visible points.

### 🎛️ Interactive Filters

The dashboard includes filters for:

* Country
* Month

# 2. 🛒 Superstore Sales Dashboard

## 📌 Overview

The **Superstore Sales Dashboard** provides an interactive overview of sales, profit, orders, products, regions, categories, and customer segments.

### 🎯 Objective

To visualize business performance and understand:

* Overall sales
* Profit
* Orders
* Quantity sold
* Category and regional performance
* Top products
* Sales trends
* Customer segment contribution

### 📊 Key Metrics

| Metric         |        Value |
| -------------- | -----------: |
| Total Sales    |   **$2.30M** |
| Total Profit   | **$286.40K** |
| Total Orders   |    **5,009** |
| Total Quantity |      **38K** |

### 🔍 Key Insights

* Total sales reached approximately **$2.30M**.
* Total profit was approximately **$286.40K**.
* The dashboard contains **5,009 orders**.
* Approximately **38K units** were sold.
* Among the displayed category-region combinations, **Technology in the East** recorded approximately **$265K** in sales.
* **Furniture in the West** recorded approximately **$253K**.
* **Technology in the West** recorded approximately **$252K**.
* Sales show a slight decline from **2011 to 2012**.
* Sales increased significantly from **2012 through 2014**.
* The highest visible annual sales level occurs in **2014**, at approximately **$735K**.
* The **Consumer segment** contributes the largest share of sales at **50.56%**.
* The **Corporate segment** contributes **30.74%**.
* The **Home Office segment** contributes **18.70%**.

### 🎛️ Dashboard Analysis

The dashboard provides visualizations for:

* Sales by category and region
* Top 10 products
* Sales trend over time
* Sales distribution by customer segment

# 4. 🎓 Student Performance Dashboard

## 📌 Overview

The **Student Performance Dashboard** provides an interactive visual overview of student population, department distribution, gender distribution, subject performance, and average marks.

### 🎯 Objective

To visualize student data and understand:

* Total number of students
* Department distribution
* Gender distribution
* Subject-wise average marks
* Student-level performance
* Semester-level information

### 📊 Key Metrics

| Metric                            |   Value |
| --------------------------------- | ------: |
| Total Students                    | **500** |
| Male Students                     | **274** |
| Female Students                   | **226** |
| Highest Displayed Subject Average |  **77** |

### 🔍 Key Insights

* The dashboard contains **500 students**.
* There are **274 male students** and **226 female students**.
* Male students represent approximately **54.8%** of the student population.
* Female students represent approximately **45.2%** of the student population.
* The **Computer** and **CSE** departments each have **128 students**.
* The **AIDS** department has **127 students**.
* The **IT** department has **117 students**.
* The highest displayed average mark is **77** for **Cryptography and Network Security**.
* **Engineering Mathematics** has an average of **73**.
* **Database Management** has an average of **72**.
* Several displayed subjects have average marks around **71**.
* The dashboard provides student-level average marks through a detailed table.
* Performance can be explored by **subject, department, and semester**.

### 🎛️ Interactive Filters

The dashboard includes:

* Subject filter
* Department filter
* Semester filter

Departments include:

* AIDS
* Computer
* CSE
* IT
